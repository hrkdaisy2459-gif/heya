# へや

画面のすみに小さく置いておく「自分の部屋」。部屋の家具がそのまま作業用の道具になっています。

| 家具 | 道具 | できること |
|---|---|---|
| 壁の時計 | アラーム | 時刻を決めて1回鳴らす（鳴ったら自動でオフ） |
| タイマー棚 | タイマー | 1〜45分のボタンですぐスタート／好きな分数／一時停止・リセット |
| つくえ | メモ帳 | 1枚のメモ。自動で保存 |
| コルクボード | やること | 追加・チェック・削除。未完了の数だけ付せんが貼られる |

飾りとして、まど（時間帯で空の色が変わる）、ランプ（クリックで点灯）、本だな、観葉植物、ポスター、ラグがあります。

## 使い方

- **部屋を見回す**: ホイール、背景をドラッグ、左右の矢印キー、端の ‹ › ボタン
- **道具を使う**: 家具をクリック
- **模様替え**: 右上の鉛筆ボタン。下のカタログから家具を追加し、ドラッグで移動します。床の家具は上下にドラッグすると手前と奥に動きます。× でしまえます
- 床をクリックすると住人がそこへ歩きます。住人をクリックすると話します
- Esc: 鳴っている音を止める → パネルを閉じる → 模様替えを終える

## 起動

インストールは不要です。公開ページを Chrome か Edge で開き、右上の **小窓ボタン** を押してください。へやが小さな窓になり、いつも画面の手前に表示されます。
小窓は端をドラッグして大きさを変えられます。元のタブは閉じずに裏に置いておいてください（閉じると小窓も閉じます）。

アドレスバーの「アプリをインストール」から入れておくと、デスクトップやスタートメニューからすぐ開けます。

### デスクトップ版（任意・Node.js がある場合）

```sh
cd desktop
npm install
npm start
```

## 構成

```
index.html            入口のページ
manifest.webmanifest  アプリとしてインストールするための設定
src/room.css
src/room.js           部屋の描画・家具・道具・小窓。依存ライブラリなし
desktop/              Electron 版（任意）
```

データ（家具の配置、メモ、やること、アラーム、タイマー）は `localStorage` に保存されます。

### 奥行きの出し方

ほぼ真横から見た部屋で、奥の壁と床の境目を基準に、手前にある物ほど少し大きく、少し下に、画面の中心から外側へずらして描いています。
スクロールすると床の板目の傾きと左右の壁が変わるので、横スクロールでも少し立体的に見えます。

### 家具を増やすには

`src/room.js` の `TYPES` に1つ追加します。`w`/`h` が絵の大きさ、`art()` が SVG の中身、壁に掛けるなら `wall: true` と `y`（下端の高さ）を付けます。
