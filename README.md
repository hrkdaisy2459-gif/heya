# へや

画面のすみに小さく置いておく、ドット絵の「自分の部屋」。部屋の家具がそのまま作業用の道具になっています。部屋には女の子が住んでいて、うろうろしたり話しかけてくれたりします。

| 家具 | 道具 | できること |
|---|---|---|
| 壁の時計 | アラーム | いくつでも登録できる。曜日を選ぶと毎週、選ばないと1回だけ鳴る |
| タイマー棚 | タイマー／ポモドーロ | 1〜45分ですぐスタート。ポモドーロは「集中→休憩」を自動でくり返す |
| つくえ | メモ帳 | 何ページでも。自動で保存 |
| コルクボード | やること | 追加・チェック・削除。未完了の数だけ付せんが貼られる |
| カレンダー | 予定 | 日付ごとに予定を書ける。当日は女の子が教えてくれる |
| ウォーターサーバー | リマインダー | 水分補給・姿勢・目の休憩を、決めた間隔で声かけ |
| ラジオ | BGM | 雨・焚き火・波・虫の声・オルゴール（音はブラウザの中で作っている） |
| クローゼット | きせかえ | 女の子の髪型・髪の色・服 |
| トロフィー棚 | がんばり記録 | ★の数、今日と7日間の集中時間、ごほうび一覧 |
| ドア | 部屋の行き来 | へや ⇔ キッチン |

飾り：まど（時間帯・季節・本物の天気で外が変わる）、ランプ、テレビ、ソファ、ベッド、本だな、観葉植物、ポスター、ラグ、ねこ、冷蔵庫、キッチン台、テーブル、金魚鉢（ごほうび）。

### 女の子

- 机で作業（ポモドーロの集中中はずっと机に向かう）、ソファでくつろぐ、ベッドでお昼寝（深夜は寝てしまう）、ねこをなでる、窓の外をながめる、などを自分で選んで動く
- 時間帯や天気、予定に合わせて話しかけてくれる。右上の歯車から名前をつけられる

### ★とごほうび

やることを完了すると★1、ポモドーロの集中を1回終えると★2、5分以上のタイマーを最後まで使うと★1。
★がたまると、服・髪型・髪の色・壁紙・家具が届く。

## 使い方

- **部屋を見回す**: ホイール、背景をドラッグ、左右の矢印キー、端の ‹ › ボタン
- **道具を使う**: 家具をクリック
- **模様替え**: 右上の鉛筆ボタン。下のカタログで「家具・壁紙・床」を選べます。家具はドラッグで移動、床の家具は上下にドラッグすると手前と奥に動きます。× でしまえます。部屋ごとに別の模様替えができます
- **せってい**: 右上の歯車。女の子の名前、天気を表示する地域、引っ越し（別のパソコンへデータを移す）
- 床をクリックすると住人がそこへ歩きます。住人をクリックすると話します
- Esc: 鳴っている音を止める → パネルを閉じる → 模様替えを終える

## 起動

インストールは不要です。公開ページを Chrome か Edge で開き、右上の **小窓ボタン** を押してください。へやが小さな窓になり、いつも画面の手前に表示されます。
小窓は端をドラッグして大きさを変えられます。元のタブは閉じずに裏に置いておいてください（閉じると小窓も閉じます）。

アドレスバーの「アプリをインストール」から入れておくと、デスクトップやスタートメニューからすぐ開けます。

### デスクトップ版（任意・Node.js がある場合）

```sh
cd desktop
npm install
npm start
```

## 構成

```
index.html            入口のページ
manifest.webmanifest  アプリとしてインストールするための設定
src/room.css
src/pixel.js          ドット絵の素材（家具・女の子・壁紙・床・窓の外）
src/sound.js          アラーム音・お知らせ音・BGM
src/room.js           部屋の描画・道具・小窓。依存ライブラリなし
desktop/              Electron 版（任意）
```

データはブラウザの `localStorage` に保存されます。別のパソコンに移すときは、せっていの「引っ越しコード」を使います。
天気は [Open-Meteo](https://open-meteo.com/)（登録不要の無料API）から取得します。

### 奥行きの出し方

ほぼ真横から見た部屋で、奥の壁と床の境目を基準に、手前にある物ほど少し大きく、少し下に、画面の中心から外側へずらして描いています。
スクロールすると床の板目の傾きと左右の壁が変わるので、横スクロールでも少し立体的に見えます。

### 家具を増やすには

`src/pixel.js` の `TYPES` に1つ追加します。`w`/`h` が絵の大きさ（ドット）、`draw(P)` が描き方です。`P.r`（四角）、`P.ell`（楕円）、`P.map`（文字で描いたドット絵）などで描くと、外側のふち取りは自動で付きます。壁に掛けるなら `wall: true` と `y`（下端の高さ）を付けます。
